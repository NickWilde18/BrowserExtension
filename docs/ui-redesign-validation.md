# 设计状态集 07 实施与验证

本轮采用已选定的学校校徽、紫色语义色、360px 基准宽度、中英文和系统明暗主题。
插件原生工具栏弹窗受浏览器最大高度约束，使用 600px 高度，固定页头和停止入口，中部独立滚动；不照搬设计画布的 650px 高度。

## 已接入的界面与集成点

| 接触点 | 实现与验证 |
| --- | --- |
| 设计 token → 页面资源 → 构建产物 | `theme.css` 共用颜色/字号/控件样式；构建复制静态资源；控制条在关闭的 shadow root 中使用同值 token，校徽内联；生产与测试构建需一并验证 |
| 确认门 → ConversationControl → 控制条 | 对话级等待计数，只在有无等待变化时刷新；控制条显示等待、接管、交接、重新查看与收起状态；单元回归及真实插件控制条测试 |
| 控制条 → 后台接管/继续 | 保留真实点击、document/frame、epoch、token 校验，等待停止回执后才显示已接管；真实浏览器用例覆盖 |
| 确认窗口 → PromptManager | 事实块、来源对话、脚本默认收起、默认拒绝焦点、两档站点允许、提交中禁用、后台接收后关闭；超时保留只读过期页，用户关窗再清理 |
| 自己输入 → 页面 → 完成/超时 | 原网页输入及完成保留；超时说明不声称页面未变化；确认与六类超时测试覆盖 |
| SiteStore → PopupState → 授权列表 | 按域名分组，逐条展示长期/当前/其他对话授权；每站点一个移除入口，沿用原站点级 revoke；缺失标题显示未命名，不伪造标题 |
| 当前页 → 分享/取消 | 没有最近对话时不给未知下一段对话共享；助手打开或用户共享的页面均可撤销归属，保留网页，断开附着并移除控制条 |
| PopupState → 停止/逐对话继续 | 停止时逐对话继续禁用，后台也检查 stopped；全局恢复不恢复已接管对话 |
| 高级设置 → 原生权限 → 切服 | 先校验来源格式，再说明权限，从真实点击申请，再确认清理授权/共享/接管状态；真实传输切服测试覆盖 |
| 隐私与关于 | 按设计披露模型/历史、Cookie 监听、脚本可能访问的数据；没有虚构帮助邮箱，署名保留待核定标记 |
| Gate → ActionContext → ResultFrame | `approvals` 只带种类、来源、结果类别，成功和错误均附；空数组表示执行期间无需确认，缺字段表示未记录 |
| ResultFrame → Chat → detail → UI | Chat 单独补丁接通 `detail.approvals`，缺/空区别保留；本轮 UI 仓读取被环境拒绝，未改 UI，尚未完成三仓真实联调 |
